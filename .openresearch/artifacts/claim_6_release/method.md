# Method

The checker validates an explicit release inventory against the exact Section 5
contract. The minimum reported workload is 3 anchor sizes times 5 negative
ratios times 320M processed samples, or 15 models and 4.8B processed samples
before any repeated runs needed for uncertainty.

No CPU runtime is guessed because the paper-specific implementation, dataset
objects, and model configuration needed for a calibrated throughput estimate
are absent.
